# 答辩三句（乙 · 定稿 · 9/29）

给丙放 PPT 第一页 / 视频开场。**不要第四句**。数字抄 `docs/实验记录.csv`，改数字先改 csv。

---

1. 官方 YOLOv8n 算法的检测头最小步长是 8，而教室后排大约 20 像素的头，到这一层只剩下 1~2 格，位置几乎被缩没，所以会漏，框也会飘动。步长 4 的 P2 在骨干网络里已经算出来了，却没有接到颈部，这一层没有参与画框。

2. 我们只修改了颈部：先把 P2 接上，检测头改为看四个尺度；特征图对齐之后，把 Concat 换成加权融合 \(F=\sum w_i X_i\)，权重非负，加起来等于 1。没有改动骨干网络。

3. 验证集相同，输入都是 640。mAP50 从 0.929 到接上 P2 之后的 0.936，加权之后是 0.933，参数量大约 3M。加权的结构没有比只接入 P2 更高。
