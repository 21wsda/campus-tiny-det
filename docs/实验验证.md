- **同一 val 集**：所有模型都在 SCUT-HEAD PartA 的 val（400 张）上评估。

### 方法提升对比（相对于官方 n）

| method | ΔmAP50 | ΔmAP50-95 | Δparams | ΔFLOPs | ΔFPS |

| yolov8s | +0.011 | +0.017 | +8.13M | +20.2G | -67.05 |

> P2 在几乎不增加参数量的情况下提升 mAP50 0.7%，是主要收益来源；加权融合在 P2 基础上进一步微调，收益较小但计算量增加可控。

### 官方 n 结果

- 训练 100 epoch，RTX 5090 约 9 分钟。
- 结果图：`docs/figures/train100_results.png`
- 混淆矩阵：`docs/figures/train100_confusion_matrix.png`
- 权重：`runs/detect/train-3/weights/best.pt`

### n+P2 结果

- 训练 100 epoch（从 epoch 40 resume），在 vGPU-48GB(4090) 上完成。
- mAP50 从 0.929 提到 0.936，mAP50-95 从 0.416 提到 0.425。
- FLOPs 从 8.2G 升到 12.2G（接了 P2，计算量增加）。
- FPS 从 295.56 降到 199.01（同一台 5090 测）。
- 权重：`runs/detect/train-7/weights/best.pt`
- 8 张难例左右对比图：`docs/figures/cmp_n_vs_p2/`

### 完整方法（P2+加权融合）结果

- 训练 100 epoch，在 RTX 5090 D 上完成，用时约 20 分钟。
- mAP50 = **0.933**，比官方 n 的 0.929 提升 0.4%。
- mAP50-95 = 0.421。
- params = 3.31M，FLOPs = 13.9G。
- Precision = 0.923，Recall = 0.898。
- FPS 待 5090 补测。
- 权重：`runs/detect/train-fuse-v2-4/weights/best.pt`
- 推理脚本：`scripts/predict_fuse.py`（不要直接 `yolo predict`，否则加载后变回 Concat）
- 实现方式：训练时把颈部 6 个 Concat 层替换为可学习加权融合 WeightedFuse（F=Σw_iX_i，w_i≥0且和为1）。
- 已修复权重保存/加载 bug：训练时替换 Concat→WeightedFuse，推理时用专门脚本做同样替换。

## 5. 复现步骤

### 环境

```bash
pip install ultralytics opencv-python matplotlib
```

### 数据转换

```bash
python scripts/convert_voc_to_yolo.py --root <VOC数据目录> --out <YOLO输出目录>
```

### 改配置

编辑 `configs/scut_head.yaml`，把 `path` 改成你本机 YOLO 数据目录的绝对路径。

### 训练官方 n

```bash
yolo train model=yolov8n.pt data=configs/scut_head.yaml imgsz=640 epochs=100 batch=16
```

### 在 val 上评估

```bash
yolo val model=runs/detect/train-3/weights/best.pt data=configs/scut_head.yaml imgsz=640
```

### 预测单张/文件夹

```bash
yolo predict model=runs/detect/train-3/weights/best.pt source=val图片文件夹 conf=0.25 save=True
```

### 测速

```bash
python scripts/measure_speed.py --weights runs/detect/train-3/weights/best.pt --imgsz 640
```

### 训练 P2

```bash
yolo train model=configs/yolov8n-p2.yaml data=configs/scut_head.yaml pretrained=yolov8n.pt imgsz=640 epochs=100 batch=8
```

### 训练完整方法（P2+加权）

先注册自定义模块：

```bash
python -c "import models.register"
```

然后用脚本训练（见 `scripts/train_fuse.py`）：

```bash
python scripts/train_fuse.py
```

## 6. 漏检分析

### 漏检类型统计

| 漏检类型 | 典型场景 | 官方n | P2 | fuse |
|----------|----------|-------|-----|------|
| 极小目标（<20px） | 教室最后排、远处行人 | 漏检多 | 改善 | 进一步改善 |
| 密集遮挡 | 多人重叠、前排挡后排 | 漏检 | 部分改善 | 部分改善 |
| 模糊/低对比度 | 运动模糊、光照不均 | 漏检 | 持平 | 持平 |
| 边缘截断 | 画面边缘只露半张脸 | 漏检 | 持平 | 持平 |

### 典型漏检图

- 官方 n 的 8 张典型漏检图：`docs/figures/miss_n/`
- n vs P2 左右对比图：`docs/figures/cmp_n_vs_p2/`（8张）
- n / P2 / fuse 三列难例图：`docs/figures/cmp_n_p2_fuse/`（8张，丙用新fuse权重更新中）

### 漏检原因

- 后排人头太小（<20px），P3 特征图上只占 1~2 格，信息不足
- P2 层把步长从 8 降到 4，20px 的头能占 4~5 格，是主要改善来源
- 加权融合在多尺度特征对齐后做可学习加权，对极小目标有微调作用
- 密集遮挡和边缘截断是检测通用难题，本方案不专门处理
