## 4. 剪映操作提示（省时间）

1. 先建 1920×1080 / 30fps 项目，把所有素材拖进媒体区
2. 图片默认时长改成 **2 秒**（设置→剪辑→图片默认时长），段 1 的轮播直接对
3. 推拉用「基础→缩放」关键帧，别用生硬的转场
4. 字幕：先导出旁白音频，用「文本→识别字幕」自动生成，再逐条改错字
5. 段 5 的字幕卡直接用「文本」+ 深色背景，不要找不存在的实拍
