校园监控中，后排人头只有十几像素。YOLOv8n 的最小检测步长为 8，小目标在特征图上只占 1～2 格，会漏检。模型变大，边缘设备难以运行。

本算法只改 YOLOv8n 的颈部：把步长为 4 的 P2 特征接入检测头，并把特征拼接改为可学习的加权融合。骨干保持不变。

在 SCUT-HEAD PartA 上，92.4% 的框不到 32 像素宽。接入 P2 后，mAP50 从 0.929 提高到 0.936，参数量为 2.93M，计算量为 12.2 GFLOPs，速度为 199 FPS，约为实时的 6.6 倍。加权融合的 mAP50 为 0.933，未超过前者。在 TinyPerson 上，mAP50 从 0.127 变为 0.124，基本持平。极端远景仍需用现场数据微调。
